# Clone-MC

一个用单文件 C++ 实现的 Minecraft 风格渲染与游戏逻辑项目。

## 简介

Clone-MC 是一个从零开始构建的 Minecraft 风格项目，目标是在**单个 `main.cpp` 文件**里复刻 Minecraft 的核心细节：区块系统、地形生成、方块交互、实体掉落、光照、伤害、物品栏等。

当前状态：地形渲染、区块 VBO、破坏/放置、物品栏、心心、伤害系统已跑通，正在推进区块动态加载与光照系统。

## 技术栈

- **语言**：C++17
- **图形 API**：OpenGL 3.3 Core
- **窗口/输入**：GLFW
- **数学库**：GLM
- **纹理加载**：stb_image
- **文字渲染**：stb_easy_font
- **地形噪声**：Reputeless/PerlinNoise
- **OpenGL 加载**：GLAD

## 文件结构

| 文件 | 说明 |
| :--- | :--- |
| `main.cpp` | 全部核心逻辑，包括渲染、地形、实体、UI、伤害系统 |
| `block_load.h` | 纹理数组加载与等轴测图标工具 |
| `README.md` | 本文件 |

## 已实现功能

- **地形生成**：基于 Perlin 噪声的高度图，草/土/石/煤矿/铁矿分层
- **区块系统**：区块 VBO 合并 + 视锥剔除
- **方块交互**：射线检测、破坏动画、硬度系统、放置方块
- **物品栏**：9 格快捷栏、数字键/滚轮切换、等轴测 3D 图标
- **掉落物**：破坏方块后生成物品实体，带重力、漂浮、拾取
- **玩家系统**：AABB 碰撞、跳跃、重力、摔落伤害、窒息伤害、虚空伤害
- **生命值**：10 颗心，支持满心/半心/空心显示
- **昼夜循环**：平滑的天空颜色与光照过渡
- **UI**：FPS、坐标、准星、物品栏

## 构建方式

### 依赖安装（Windows + MinGW-w64）

将以下库放入 MinGW 的 `include` 和 `lib` 目录：

- GLAD
- GLFW
- GLM
- stb_image / stb_easy_font
- Reputeless/PerlinNoise

### 编译命令

```bash
g++ main.cpp glad.c -o Clone-MC.exe \
    -I./include \
    -L./lib \
    -lglfw3 -lopengl32 -lgdi32 \
    -std=c++17
